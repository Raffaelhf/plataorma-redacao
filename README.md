## PostgreSQL com Docker

O projeto usa PostgreSQL rodando em Docker para desenvolvimento local.

## Subir o banco

```bash
npm run db:up
npm run db:generate
npm run db:push
npm run db:seed
```

## Usuarios de teste

- Professor: `adminprof` / `1234`
- Administrador: `Raffaeladmin` / `Raffael1@`

## Rodar o projeto

```bash
npm run dev
```

## Encerrar o banco

```bash
npm run db:down
```
